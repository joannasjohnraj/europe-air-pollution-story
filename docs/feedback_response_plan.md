\# Feedback Response Plan – Interactive PM2.5 Story



\*\*Date:\*\* 19 June 2026



\## Main feedback



The project should stay focused on one clear message:



> PM2.5 levels improved across Europe, but remaining hotspots show that the improvement is uneven.



The visualizations should not become separate map outputs. Every visualization should support this main message.



\## Updated story focus



The story should guide the reader through the following logic:



1\. What is PM2.5 and why does it matter?

2\. Europe improved overall.

3\. But some hotspot areas still remain.

4\. These hotspot areas should be explored more closely.

5\. The reader should be able to interact with the map and inspect regions.



\## Important design feedback



The current prototype is a useful first step, but it is still too static.  

It works more like a clickable slideshow than an interactive data story.



The next prototype version should include:

\- a real interactive map

\- zooming and panning

\- clickable hotspot regions

\- annotations

\- explanatory text that changes based on interaction

\- view switching between overview, change, and hotspot layers



\## Persistent hotspot map issue



The persistent hotspot map is useful analytically, but it may confuse readers if areas appear as historical hotspots even when they are not current hotspots.



Therefore, the story should focus first on \*\*current 2024 hotspots\*\*.



A better use of persistence is:



> For the areas that are hotspots now, how long have they been a problem?



This connects persistence more directly to the main message.



\## Role of EEA / EU sources



The project should use EEA and EU information as the main source for background knowledge about:

\- what PM2.5 is

\- why it is harmful

\- where PM2.5 comes from

\- why air pollution remains a problem

\- policy thresholds and air quality goals



The project’s own calculations do not replace official statistics.  

They are used to build a focused visual story from the raster data and support interactive exploration.



\## Updated implementation priority



The next implementation priority is not more static maps.



The next priority is:



> Build an interactive map prototype that lets the reader explore the contrast between overall improvement and remaining hotspots.
