# PM2.5, European air quality data for 2008, (interpolated data)

The data set provides concentrations for the air pollutants PM2.5 at 1 km grid combining monitoring air quality data in a ‘regression-interpolation-merging mapping’ methodology and the observational values of the air quality monitoring stations used in the interpolation. It covers Europe for the year 2008. It provides estimates for human health related indicators of pollutants PM2.5 (annual average) for the year 2008.https://sdi.eea.europa.eu/geonetwork/srv/api/records/2e62999e-be64-419b-af46-362b6f8129cb
